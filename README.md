# 🏐 PAPS + 인성 AI 팀빌딩

체육수업 팀을 **PAPS(체력)로 1차 균등 → 스포츠 인성 4덕목(성실·협동·정의·배려)으로 2차 균등**하게 편성하는 웹앱입니다.
설치나 서버 없이 브라우저만 있으면 동작합니다. 자료는 브라우저(localStorage)에만 저장됩니다.

프로젝트 아고라(AI 융합교육 교사연구회) "AI 체육수업 팀빌딩" 연구용으로 만들었습니다.

**👉 바로 사용하기: https://dlwnsdyd21-del.github.io/agora-teambuilder/**

## 실행

- 가장 간단한 방법: `index.html`을 더블클릭해서 브라우저(Chrome·Edge)로 엽니다.
- 로컬 서버로 열고 싶다면:

```bash
python -m http.server 8765
```

후 `http://localhost:8765` 접속.

- GitHub Pages 배포: 저장소 `dlwnsdyd21-del/agora-teambuilder`의 `main` 브랜치 루트에서 바로 서비스됩니다(빌드 없음). `main`에 푸시하면 1~2분 뒤 반영됩니다.

## 사용 순서

1. **데이터 불러오기** — PAPS 자료와 인성 설문 자료를 각각 올립니다(파일 드롭, 파일 선택, 또는 엑셀 표 붙여넣기). 열은 자동 인식되며 매핑 표에서 고칠 수 있습니다. 두 자료는 **번호**(없으면 이름) 기준으로 합쳐집니다.
2. **명단 확인** — 번호·이름·성별을 고치고, 자료가 없는 학생은 PAPS 총점/등급이나 4덕목 점수를 직접 입력합니다. 결측은 학급 평균으로 채워지고 `대체` 배지가 붙습니다.
3. **편성 설정** — 팀 수, 성별 균형(기본 켬), PAPS 허용편차(τ), 제약(함께 넣기·떨어뜨리기·팀 고정)을 정하고 **팀 편성하기**를 누릅니다. **다시 섞기**는 시드를 바꿔 다른 균등 편성을 만듭니다.
4. **결과** — 팀 카드(드래그로 이동, 클릭 두 번으로 교환), 팀 균형표, 지표별 팀 평균 분포, 4덕목 레이더, 공정성 점수. **학생용 보기**를 켜면 개인 점수를 숨기고 팀 구성과 팀 단위 균형만 보여줍니다.
5. **내보내기** — 게시용 팀 명단 엑셀(개인 점수 없음), 교사용 엑셀(개인 점수 포함), 인쇄, 세션 JSON 저장/열기, 빈 입력 양식.

상단의 **학급 저장**으로 여러 학급을 브라우저에 따로 보관하고 불러올 수 있습니다.

## 읽을 수 있는 자료 형식

| 자료 | 형식 | 처리 |
|---|---|---|
| 나이스 결과조회 (권장) | NEIS "학급별건강체력평가조회" xlsx (평가결과조회 → 학급별조회 → 엑셀). 2줄 헤더(영역 → 종목·점수·등급), 페이지마다 반복되는 헤더 행 포함 | 나이스가 계산한 영역별 점수·총점·등급을 그대로 사용. 파일에 성별이 없으므로 **영역 점수와 기준표를 대조해 성별·학년(기준표)을 자동 추정**하고 명단에 `추정` 배지로 표시(수정 가능) |
| PAPS 원기록 | NEIS "학급별일괄입력" xlsx (왕복오래달리기 · 앉아윗몸앞으로굽히기 1/2차 · 윗몸말아올리기 · 제자리멀리뛰기 1/2차 · 신장 · 체중). 팔굽혀펴기·악력·50m달리기 열도 인식 | 1·2차 중 좋은 기록 사용. **공식 기준표**(학교건강검사규칙 [별표 4] 2025.3.10 개정, [별표 5] 점수 산출 규칙)로 종목당 0~20점을 매기고 5영역(심폐지구력·유연성·근력·순발력·체지방) 합계 → **PAPS 총점(100점 만점)**, 80점↑ 1등급 … 19점↓ 5등급. 성별·학년이 필요하며, 성별이 없는 학생은 학급 내 백분위×20점(상대점수)으로 대체하고 표시. 영역이 빠지면 100점 만점으로 환산 |
| PAPS 계산값 | 번호·이름 + `PAPS 총점`(100점 만점) 또는 `PAPS 등급`(1~5) 열 | 총점은 그대로, 등급은 대표 점수(1→90, 2→70, 3→50, 4→30, 5→10) |
| 인성 32문항 | 구글폼 응답 시트: `타임스탬프`·`학교`·`학번`("10130 홍길동" = 1학년 1반 30번) + 헤더가 `1. …`~`32. …`인 객관식 32문항(응답 "④ 그렇다" 등 글자도 1~5점으로 변환). 헤더가 `1`~`32`, `Q1`, 문항 원문이어도 인식 | 성실 1–8 · 협동 9–16 · 정의 17–24 · 배려 25–32 평균(8문항 중 5개 이상 응답 시). B1~B5 보조문항·학교·타임스탬프 열은 자동 제외 |
| 인성 4덕목 | `성실`·`협동`·`정의`·`배려` 열(1~5점) | 그대로 사용 |
| 성별 | `성별` 열(남/여) | 어느 파일에 있든 읽음 |

`sample/` 폴더에 가명 샘플(PAPS NEIS 양식, 구글폼 32문항 양식, 4덕목 CSV)이 있습니다.

## PAPS 점수 산출 (공식 규칙)

- 종목별 1~5등급 구간은 학교건강검사규칙 [별표 4](국가법령정보센터, 2025.3.10 개정)를 그대로 넣었습니다(`js/paps_table.js`, 초3~고3 남·여, 왕복오래달리기·앉아윗몸앞으로굽히기·윗몸말아올리기·팔굽혀펴기·악력·제자리멀리뛰기·50m달리기·BMI).
- [별표 5] 점수 규칙: 5등급 최솟값 이하 0점, 5등급 구간 3등분 → 1~3점, 4등급 4등분 → 4~7점, 3등급 → 8~11점, 2등급 → 12~15점, 1등급 구간 4등분 → 16~19점, 1등급 최댓값 이상 20점(등분 경계 반올림). 예) 초5 남 왕복오래달리기 23~24회 1점, 29~33회 4점, 100~101회 16점, 107회 이상 20점.
- BMI: 정상 20점(1등급). 과체중(2등급)·마름(3등급)·경도비만(4등급)·고도비만(5등급)의 등급은 공식 기준이고, 등급 안의 세부 점수는 같은 등분 규칙을 준용한 추정치입니다(NEIS 산출값과 1~2점 다를 수 있음).
- 학교급·학년은 3단계 설정에서 고르며, 파일에 `학년` 열이 있으면 학생별로 적용합니다.

## 드래프트 화면 (`draft.html`)

3단계 아래 **드래프트 화면 열기**를 누르면 학생들과 함께 보는 발표용 화면이 새 창으로 열립니다(같은 브라우저 저장소를 공유). 팀 이름을 정하고, 🎲 지명 순서 추첨 뒤 시작합니다. 결과를 저장하면 메인 4단계에 자동으로 나타납니다.

| 방식 | 진행 | 균형 유지 |
|---|---|---|
| 교사 편성 공개 | "팀 편성하기" 결과를 라운드마다 한 명씩(Space) 또는 자동으로 공개 | 알고리즘 결과 그대로 |
| 팀별 드래프트 | 성별·체력 순으로 팀 수의 2배씩 묶은 체력 구간 안에서 다시 **인성 평균이 비슷한 순으로 팀 수만큼 묶은 풀**. 한 풀의 학생들은 체력·인성 수준이 비슷하고 강점 덕목만 달라, 팀은 뱀 순서(1→K, K→1 …)로 원하는 덕목 성향(🔥성실형·🤝협동형·⚖️정의형·💙배려형)을 고름. 덕목 칩을 누르면 해당 성향 선수만 강조 | 팀마다 각 풀에서 한 명씩 → 체력·인성·성별 균형 자동 |
| 크레딧 드래프트 | 선수마다 체력·인성 백분위로 **1~10 크레딧**(체력 비중 조절 가능). 팀 예산 합계 = 전체 크레딧 합계. 예산을 넘거나 남은 인원을 채울 수 없게 되는 지명은 막힘 | 팀별 성별 정원 + 예산. 끝까지 예산 안에서 고를 수 없으면 초과 지명을 허용하고 표시 |

- **익명 드래프트**(기본 켬): 팀별·크레딧 드래프트 중에는 이름·번호 대신 출석번호와 무관한 무작위 코드("선수 07")로 보이고, 완료 후 **이름 공개하기**를 누르면 팀 보드가 뒤집히며 이름이 나타납니다. 교사는 상단의 **이름 공개** 스위치로 언제든 볼 수 있습니다.
- 공유 화면은 기본적으로 개인 점수 숫자를 숨기고 체력 등급 별(★)과 덕목 유형만 보여 줍니다(연구 설계의 개인 점수 비공개 원칙). 교사는 **상세 점수**를 켤 수 있습니다.
- 자동 지명(A키), 되돌리기(Z키), 지명 시간 제한(초 단위), 완료 시 팀 균형(공정성 점수) 표시.

## 편성 알고리즘

1. **1차 — PAPS 균등**: 성별 그룹별로 PAPS 총점 내림차순으로 서펜타인 드래프트(1→K, K→1 …). 팀 인원 차 ≤1, 성별 균형 켬이면 팀별 남·여 수 차 ≤1. 고정 학생은 먼저 배치하고, 함께/떨어뜨리기 제약은 교환으로 보수합니다.
2. **2차 — 인성 균등**: 서로 다른 팀의 두 학생(같은 성별)을 교환하거나 한 명을 이동하는 지역 탐색.
   - `Dp` = 팀 평균 PAPS 총점의 최대−최소 범위(점), `Dc` = 4덕목 각각의 (팀 평균 표준편차 ÷ 학생 표준편차) 합
   - 목적함수 `J = 1000·max(0, Dp − τ) + Dc + 0.01·Dp` → PAPS 범위를 허용편차 τ(기본 4점) 안에 유지하면서 인성 편차를 최소화
   - 시드 파생 5회 재시작 중 최솟값 채택. 같은 자료·설정·시드면 항상 같은 결과.
3. **공정성 점수** = `100 × (1 − 0.5·min(1, Dp/학생 PAPS 표준편차) − 0.5·min(1, Dc/2.0))` — 다시 섞기 결과를 비교하는 용도입니다.

PAPS와 인성 점수는 **합산하지 않고**, 인성 점수로 학생을 **서열화하거나 공개하지 않습니다**(연구 설계 원칙).

## 파일 구조

```
index.html          화면
css/style.css       스타일(인쇄·학생용 보기 포함)
js/questions.js     32문항·B문항·덕목 정의
js/paps_table.js    PAPS 공식 등급 기준표(별표 4)와 점수 산출 규칙(별표 5)
js/scoring.js       PAPS 총점(100점 만점), 덕목 평균, 결측 대체
js/algorithm.js     팀 편성(드래프트 + 지역 탐색), 통계
js/parse.js         xlsx/csv/붙여넣기 파싱, 열 자동 인식, 병합
js/state.js         세션 상태, localStorage, 되돌리기, 학급 보관
js/export.js        엑셀·JSON 내보내기, 양식
js/ui.js            렌더링·이벤트
vendor/xlsx.full.min.js   SheetJS (오프라인용)
sample/             가명 샘플 자료
test/run.js         단위 테스트
```
