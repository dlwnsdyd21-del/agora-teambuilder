# 🏐 PAPS + 인성 AI 팀빌딩

체육수업 팀을 **PAPS(체력)로 1차 균등 → 스포츠 인성 4덕목(성실·협동·정의·배려)으로 2차 균등**하게 편성하는 웹앱입니다.
설치나 서버 없이 브라우저만 있으면 동작합니다. 자료는 브라우저(localStorage)에만 저장됩니다.

프로젝트 아고라(AI 융합교육 교사연구회) "AI 체육수업 팀빌딩" 연구용으로 만들었습니다.

## 실행

- 가장 간단한 방법: `index.html`을 더블클릭해서 브라우저(Chrome·Edge)로 엽니다.
- 로컬 서버로 열고 싶다면:

```bash
python -m http.server 8765
```

후 `http://localhost:8765` 접속.

- GitHub Pages 배포: 저장소에 이 폴더를 그대로 올리고 Pages를 켜면 됩니다(빌드 없음).

## 사용 순서

1. **데이터 불러오기** — PAPS 자료와 인성 설문 자료를 각각 올립니다(파일 드롭, 파일 선택, 또는 엑셀 표 붙여넣기). 열은 자동 인식되며 매핑 표에서 고칠 수 있습니다. 두 자료는 **번호**(없으면 이름) 기준으로 합쳐집니다.
2. **명단 확인** — 번호·이름·성별을 고치고, 자료가 없는 학생은 PAPS 총점/등급이나 4덕목 점수를 직접 입력합니다. 결측은 학급 평균으로 채워지고 `대체` 배지가 붙습니다.
3. **편성 설정** — 팀 수, 성별 균형(기본 켬), PAPS 허용편차(τ), 제약(함께 넣기·떨어뜨리기·팀 고정)을 정하고 **팀 편성하기**를 누릅니다. **다시 섞기**는 시드를 바꿔 다른 균등 편성을 만듭니다.
4. **결과** — 팀 카드(드래그로 이동, 클릭 두 번으로 교환), 팀 균형표, 지표별 팀 평균 분포, 4덕목 레이더, 공정성 점수. **학생용 보기**를 켜면 개인 점수를 숨기고 팀 구성과 팀 단위 균형만 보여줍니다.
5. **내보내기** — 게시용 팀 명단 엑셀(개인 점수 없음), 교사용 엑셀(개인 점수 포함), 인쇄, 세션 JSON 저장/열기, 빈 입력 양식.

상단의 **학급 저장**으로 여러 학급을 브라우저에 따로 보관하고 불러올 수 있습니다.

## 읽을 수 있는 자료 형식

| 자료 | 형식 | 처리 |
|---|---|---|
| PAPS 원기록 | NEIS "학급별일괄입력" xlsx (왕복오래달리기 · 앉아윗몸앞으로굽히기 1/2차 · 윗몸말아올리기 · 제자리멀리뛰기 1/2차 · 신장 · 체중) | 1·2차 중 좋은 기록 사용. BMI는 정상범위(18.5~23) 안이면 0, 밖이면 거리만큼 감점. 영역별로 학급(성별이 전원 있으면 성별) 안에서 표준점수 z를 내고 평균 → **PAPS 종합(z)** |
| PAPS 계산값 | 번호·이름 + `PAPS 총점` 또는 `PAPS 등급` 열 | 총점은 그대로, 등급(1이 최상)은 부호를 바꿔 z화 |
| 인성 32문항 | 헤더가 `1`~`32`, `1.`, `Q1`, 또는 문항 원문(구글폼 응답 시트) | 성실 1–8 · 협동 9–16 · 정의 17–24 · 배려 25–32 평균(8문항 중 5개 이상 응답 시). B1~B5 보조문항은 자동 제외 |
| 인성 4덕목 | `성실`·`협동`·`정의`·`배려` 열(1~5점) | 그대로 사용 |
| 성별 | `성별` 열(남/여) | 어느 파일에 있든 읽음 |

`sample/` 폴더에 가명 샘플(PAPS NEIS 양식, 구글폼 32문항 양식, 4덕목 CSV)이 있습니다.

## 편성 알고리즘

1. **1차 — PAPS 균등**: 성별 그룹별로 PAPS 종합(z) 내림차순으로 서펜타인 드래프트(1→K, K→1 …). 팀 인원 차 ≤1, 성별 균형 켬이면 팀별 남·여 수 차 ≤1. 고정 학생은 먼저 배치하고, 함께/떨어뜨리기 제약은 교환으로 보수합니다.
2. **2차 — 인성 균등**: 서로 다른 팀의 두 학생(같은 성별)을 교환하거나 한 명을 이동하는 지역 탐색.
   - `Dp` = 팀 평균 PAPS의 최대−최소 범위, `Dc` = 4덕목 각각의 (팀 평균 표준편차 ÷ 학생 표준편차) 합
   - 목적함수 `J = 1000·max(0, Dp − τ) + Dc + 0.05·Dp` → PAPS 범위를 허용편차 τ(기본 0.3 z) 안에 유지하면서 인성 편차를 최소화
   - 시드 파생 5회 재시작 중 최솟값 채택. 같은 자료·설정·시드면 항상 같은 결과.
3. **공정성 점수** = `100 × (1 − 0.5·min(1, Dp/1.0) − 0.5·min(1, Dc/2.0))` — 다시 섞기 결과를 비교하는 용도입니다.

PAPS와 인성 점수는 **합산하지 않고**, 인성 점수로 학생을 **서열화하거나 공개하지 않습니다**(연구 설계 원칙).

## 파일 구조

```
index.html          화면
css/style.css       스타일(인쇄·학생용 보기 포함)
js/questions.js     32문항·B문항·덕목 정의
js/scoring.js       PAPS z점수, 덕목 평균, 결측 대체
js/algorithm.js     팀 편성(드래프트 + 지역 탐색), 통계
js/parse.js         xlsx/csv/붙여넣기 파싱, 열 자동 인식, 병합
js/state.js         세션 상태, localStorage, 되돌리기, 학급 보관
js/export.js        엑셀·JSON 내보내기, 양식
js/ui.js            렌더링·이벤트
vendor/xlsx.full.min.js   SheetJS (오프라인용)
sample/             가명 샘플 자료
test/run.js         단위 테스트
```

## 테스트

```bash
node test/run.js
```
